# Playbook and Patches to Prepare Hosts/VMs for CoreMedia

`coremedia-node-preparation`

The [Ansible][ansible] playbook in this repository is intended for preparation
of CI systems and other hosts, which need to be able to let [CoreMedia][coremedia]
CMS-9 or LiveContext 3 run on them or build the workspaces for them without any
other installation steps necessary.

The supported target operating systems are CentOS, Debian, RedHat, and Ubuntu.

Find the repository at [Codeberg][codeberg] with a mirror at [GitLab][gitlab].


Please prefer to find this repository and all the related information and discussions at

* Gitlab under https://gitlab.com/provocon/coremedia-node-preparation
* Codeberg under https://codeberg.org/provocon/coremedia-node-preparation
